# 한빛식당(가상) 점심 기록 정제 규칙 — lunch_rules.md

- 원본: `labs/day3/lab-c/hanbit_lunch_log.csv` (UTF-8 BOM, 읽기만 함)
- 코드: `scripts/lunch_clean.py` (이 표 그대로) → 결과 `lunch_clean.csv` · 고친 줄 수 `lunch_clean_log.md`
- 적용 순서: R1 → R2 → R3 → R4 → R5 → **R10** → R6 → R7 → R8 → R9 (R10은 나중에 더한 규칙이라 번호는 10이지만, R6가 출근예정을 쓰므로 R6보다 먼저)

| 번호 | 규칙 | 왜 |
|---|---|---|
| R1 | 날짜를 `YYYY-MM-DD`로 — `2026.3.2` · `2026/03/02` · `3월 2일`. 연도가 없으면 10–12월은 2025년, 1–9월은 2026년 | 형식이 네 가지로 섞여 있어 날짜순 정렬 · 같은 날짜 찾기 · 기간 나누기를 할 수 없다 |
| R2 | 요일은 적힌 글자를 버리고 날짜에서 다시 계산한다(월 · 화 · 수 · 목 · 금) | `월요일` · `Mon`처럼 표기가 섞였고, 날짜와 다른 요일이 적힌 줄도 있다 |
| R3 | 비고가 `휴무`인 줄은 뺀다 | 식당이 쉰 날(식수 0)은 '안 온 날'이 아니라 '안 연 날'이라 평균 · 예보를 끌어내린다 |
| R4 | 같은 날짜가 두 줄이면 비고에 `재집계`가 든 줄을, 없으면 나중 줄을 남긴다 | 같은 날이 두 번 세어지면 그날 무게가 두 배가 된다. 재집계 줄이 맞는 값이라고 적혀 있다 |
| R5 | 식수가 빈칸인 줄은 뺀다(지어내지 않는다) | 식권 기계 고장으로 못 센 날이다. 채워 넣으면 없는 사실을 만드는 것이다 |
| R10 | 출근예정 빈칸은 같은 요일의 바로 앞 기록 4개(출근예정이 있는 줄)의 가운데 값(median)을 반올림해 채운다 | 출근예정은 식수와 달리 크게 흔들리지 않는 값이고, R6 판정과 '100명당 식수'에 꼭 필요하다 |
| R6 | 식수가 출근예정보다 많거나 출근예정의 20% 미만이면 그 줄을 뺀다. **`수기 집계` 줄 결정: 뺀다** — 이유: 프롬프트에 이유가 적혀 있지 않음(확인 필요) | 출근한 사람보다 많이 먹을 수 없고, 20% 미만은 집계 실수일 가능성이 크다 |
| R7 | 날씨는 맑음 · 흐림 · 비 · 눈 넷으로 — `맑` · `sunny` → 맑음 / `구름많음` · `cloudy` → 흐림 / `rain` · `우천` · `소나기` · `흐리고 비` → 비 / `snow` → 눈 / 빈칸 → 모름 | 같은 날씨가 여러 이름으로 흩어지면 '비 오는 날' 같은 비교가 틀어진다 |
| R8 | 최고기온은 `℃` · `°C` · 공백을 떼고 숫자만 남긴다(빈칸은 빈칸으로 둔다) | 단위 글자가 붙으면 숫자로 계산할 수 없다. 빈칸은 지어내지 않는다 |
| R9 | 이름 통일 — `돈까스` → 돈가스 · `카레라이스` → 카레 · `제육` → 제육볶음 · `치킨마요덮밥` → 치킨마요 · `김치 찌개` → 김치찌개 · `외부손님` → 외부 손님 방문 · `전사교육` → 전사 교육 | 같은 메뉴 · 행사가 다른 이름이면 메뉴별 비교와 예보 재료가 갈라진다 |

마지막 정리: 월급날 `Y` → 1 · 빈칸 → 0, 출근예정 · 식수는 정수, 날짜순 정렬, UTF-8 BOM, 열은 원본과 같은 10개.
